# 安全审查

本次审查覆盖仓库中的 Go 服务、看板认证、外部日志请求、单机启动脚本以及 Go 模块和标准库。风险按可达性及影响排序。部署端的网络、访问日志、证书和账号配置需要单独核对，代码审查无法给出入侵概率，也无法判断服务器是否已经被入侵。

| 优先级 | 风险与适用条件 | 处理 |
| --- | --- | --- |
| 高 | 旧 Go 工具链和 PostgreSQL、Redis、文本处理依赖命中可达的漏洞公告。实际影响取决于哪些接口及上游对外可达。 | 构建环境升到 Go 1.26.11，更新 pgx、go-redis、x/text 和 x/sys。使用 Go 官方漏洞库复扫。 |
| 高 | 运维页面使用 Basic Auth。公网明文 HTTP、弱密码或重复使用密码会增加凭据泄露风险。 | 应用只接受 `operator` 和正确的密码。Compose 默认将网页端口绑定到回环地址。远程使用 SSH 隧道，或由内网 HTTPS 代理控制访问和登录限速。Kibana 与 Grafana 遵循各自的权限配置。 |
| 中 | 持续缓慢发送请求或长时间保留连接会占用 HTTP 连接资源。 | 增加请求读取时限、连接空闲时限和请求头大小上限。对公网接入还需要在代理实施连接数和请求速率限制。 |
| 中 | 日志源请求失败时，传输错误可能带出上游地址和 LogQL 查询内容。 | 返回脱敏的传输错误，同时保留超时和取消的分类。 |
| 中 | 已存在的 `.env` 权限过宽时，其他本机账号可能读到数据库和告警密钥。 | 单机启动脚本把普通 `.env` 文件收紧到 `0600`，拒绝链接及非普通文件。 |

Go 复扫只涵盖 Go 代码与模块，Elasticsearch、Kibana、Logstash、Grafana 和其他镜像需要扫描实际部署的镜像版本。生产环境将采集网关限制在授权采集机可到达的内网范围，限制管理界面、`/metrics` 和 `/readyz` 的访问，并按最小权限分开配置采集写入和应用读取账号。[快速部署](quickstart.md)
